# My Responsive Website Project

## Overview
This project is a fully responsive website built using HTML5 and CSS3. It includes a navigation menu, structured content sections, and a responsive contact form using Flexbox and media queries.

## Features
- Responsive layout using Flexbox
- Contact form with validation (required fields)
- Hover and focus effects for interactivity
- Media queries for phone, tablet, and desktop views
- Clean, user-friendly interface

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

## How to Run Locally
You can open the project by double-clicking the `index.html` file or using a local server like XAMPP.
